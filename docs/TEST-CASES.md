# Ручная проверка

Автотесты: `php artisan test` (55 тестов). Ниже сценарии, которые удобно показать преподавателю руками.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Двойной клик по `start.bat` на чистом клоне | Шаги 1–6 проходят, браузер открывает афишу с 12 билетами |
| 2 | Афиша: «Сбросить кеш», затем обновить страницу | Сначала «Источник: база данных, SQL-запросов: 1», после обновления «кеш Redis, 0» |
| 3 | Открыть мероприятие, обновить страницу | Номер на штампе растёт на 1, уникальных зрителей столько же, `SADD` вернул 0 |
| 4 | Открыть то же мероприятие в другом браузере или в режиме инкогнито | Уникальных зрителей стало на 1 больше |
| 5 | Изменить цену на странице мероприятия | Сообщение об удалённых ключах, новая цена сразу видна на афише |
| 6 | Ввести цену `-5` или `дорого` | Ошибка под полем, цена не меняется |
| 7 | Лаборатория: `SET event:1:name "IT Conference" EX 120` | В панели ключей TTL идёт от 2:00 вниз, через 2 минуты ключ исчезает |
| 8 | Лаборатория: `CONFIG GET maxmemory` | `(error) Команда CONFIG в лаборатории недоступна…` |
| 9 | Лаборатория: `FLUSHDB`, затем вкладка «Сайт» | Ключи лаборатории пропали, просмотры сайта на месте |
| 10 | Выполнить команды задания 6 и нажать «Проверить задание» | Галочка у задания, в тексте лидер рейтинга |
| 11 | Открыть `/redis-test` | `Данные из Redis: Александр` |
| 12 | Открыть `/events/100/views` несколько раз | JSON, `views` растёт на 1 |
| 13 | `stop.bat`, затем обновить афишу | Красная полоса «Сайт работает без Redis», афиша читается из базы |
| 14 | Сайт на ширине 375 px | Нет горизонтальной прокрутки, билеты в одну колонку |
